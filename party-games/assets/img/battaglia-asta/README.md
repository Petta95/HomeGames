# Immagini per il gioco "Battaglia all'Asta"

Ogni sottocartella corrisponde a una categoria (`battaglia-asta.html`).
La maggior parte delle foto è stata scaricata automaticamente da Wikipedia
(licenze libere). Alcuni personaggi/serie protetti da copyright (poster,
fumetti, film) non hanno un'immagine libera disponibile: per quegli elementi
il gioco mostra automaticamente un'emoji al posto della foto, quindi funziona
comunque. Se vuoi sostituire l'emoji con una foto vera, salva il file con
ESATTAMENTE il nome indicato nell'`elenco-immagini.txt` di ogni cartella.

Formato consigliato: `.jpg`, quadrata (es. 500x500px).
