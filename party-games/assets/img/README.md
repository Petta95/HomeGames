# Immagini per il gioco "Ordina"

Ogni sottocartella corrisponde a una categoria del gioco (`ordina.html`).
Dentro ciascuna trovi un file `elenco-immagini.txt` con i nomi esatti dei
file da inserire (es. `zanzara.jpg`, `burj-khalifa.jpg`, ...).

Regole pratiche:

- Formato **`.jpg`**, idealmente quadrate (es. 400x400px) per un risultato pulito.
- Il nome del file deve corrispondere **esattamente** a quello indicato (minuscolo, trattini).
- Se un'immagine manca, il box mostra automaticamente un'icona 🖼️ al posto della foto:
  il gioco funziona comunque, quindi puoi aggiungere le immagini gradualmente.
- Per aggiungere una **nuova categoria**, crea una nuova cartella con lo stesso `id`
  usato nell'array `CATEGORIES` dentro `ordina.html` e inserisci lì le foto.
